부풀리지 않기 위해 정한 규칙

  • "누적 작성 줄"을 쓰지 않았습니다. 한 파일을 37번 커밋하면 추가 줄이 매번 더해져 실제보다 3배 가까이 부풀려집니다. 대신 git blame으로 지금 코드베이스에 살아있는 줄만 셌습니다. 그래서 146,000줄이 아니라 52,611줄입니다.
  • 내 것이 아닌 코드는 전부 뺐습니다. vendor/, node_modules/, 백업 폴더, jQuery·Bootstrap 같은 라이브러리, 데이터 파일(JSON·HTML 덤프)은 집계에서 제외했습니다.
  • 흩어진 커밋 계정을 합쳤습니다. 대소문자·표기가 다른 4개 아이덴티티(hogeun cha, hogeun.cha, Hogeun.cha)와 개인 계정 커밋을 동일인으로 병합해 510커밋을 얻었습니다.
  • "리드한 커밋"과 "내가 쓴 코드"를 절대 섞지 않았습니다. 944커밋은 내 510커밋 + 내가 지시한 팀원 5명의 434커밋입니다. 팀원 커밋은 내가 작성한 코드가 아니며, 코드 줄 수(52,611줄) 집계에는 단 한 줄도 포함하지 않았습니다. 내 팀이 아닌 개발자들의 커밋 559개는 전부 제외했습니다.
  • 한계도 밝힙니다. blame은 각 줄을 마지막으로 만진 사람에게 귀속시킵니다. 내가 지운 코드는 세지 않고, 남이 내 코드를 덮어쓴 줄도 빠집니다 — 즉 이 숫자는 보수적으로 잡힌 하한선에 가깝습니다.
