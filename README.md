# 차호근 포트폴리오

콘텐츠 구조, 시스템 구조, 코드 구조를 연결해온 경험을 다음 순서로 정리한 GitHub Pages 포트폴리오입니다.

기획 → 스토리보드 → 유저플로우 → UX → UI 디자인 → 디자인 리딩 → 퍼블리싱 → 영상 제작까지 이어지는 실무 범위를 대외비 화면 대신 공개 가능한 역할·과정·의사결정으로 설명합니다.

1. 포지셔닝
2. PUI-X 사내 프로덕트 시스템
3. 프론트엔드 구조 설계·리뷰
4. SEO / GEO
5. AI 협업 방법론
