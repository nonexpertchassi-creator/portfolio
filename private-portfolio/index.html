Case · PUI-X

반복 제작을 운영 시스템으로 바꾸다

동일 템플릿 40종을 수작업으로 제작·유지하던 구조를 문제로 정의하고, 기획·설계·구현·배포·운영을 단독으로 수행했습니다.

Before

40종을 각각 수정하는 구조

수정 요청 전달 → 40회 수작업 → 검수 → 재작업. 1px 변경도 40번의 편집과 40번의 오류 가능성으로 확산됐습니다.

문제 정의 · 수정 비용이 산출물 개수에 비례

After

데이터와 규칙으로 생성하는 구조

Excel 상품 데이터 → 단일 템플릿과 변형 규칙 → 자동 렌더·캡처 → 결과 검수. 수정 지점을 템플릿과 데이터 규칙으로 집중시켰습니다.

운영 원칙 · 수정 비용과 산출물 개수를 분리

INPUTExcel 상품 데이터
RULE단일 템플릿 + 변형 스키마
RENDER서버 렌더·자동 캡처
OUTPUT40종 결과물·ZIP
  1. 0140개 HTML 복제 검토 → 변형 간 차이 누적 → 단일 템플릿 + 변형 스키마
  2. 02브라우저 수동 캡처 검토 → 환경·절차 편차 → Playwright 서버 캡처
