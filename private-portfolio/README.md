# 차호근 비공개 포트폴리오 사이트

`index.html` 하나만으로 동작하는 정적 사이트입니다. 외부 폰트, 이미지, 라이브러리를 사용하지 않습니다.

## GitHub Pages에 올리는 방법

1. 새 저장소를 만들고 `index.html`을 저장소 최상위에 올립니다.
2. GitHub 저장소의 **Settings → Pages**에서 배포 브랜치를 선택합니다.
3. 생성된 주소에 접속하면 사이트가 열립니다.

## 주의

- 이 파일에는 `noindex`가 적용되어 있지만, 검색 노출을 줄이는 설정일 뿐 접근을 막는 보안 기능은 아닙니다.
- 공개 저장소나 공개 GitHub Pages에 올리면 URL을 아는 사람이 내용을 볼 수 있습니다.
- 대외비 제출용으로 사용할 경우 고객명·수치·공개 범위를 다시 확인하거나 접근 제어가 있는 호스팅을 사용하세요.
- 이력서용·프리랜서용을 나누지 않고 하나의 경력 포트폴리오 흐름으로 구성했습니다.
